# 纵横四海 · 文字版大航海网游（zhsh-remake）

一个**非官方**、**服务器权威**的多人在线文字网游项目，灵感与部分原始数据源自怀旧文字页游《纵横四海》（原QQ家园/苏摩科技运营，已于 2018 年停服）。本项目为独立编写的复刻与扩展作品，**与原版权方无任何关联**。

> ⚠️ **许可声明**：本项目 **禁止商用**。详见 [LICENSE](LICENSE)。非官方复刻，仅供学习研究。

## 项目简介

本项目把一个高保真复原的《纵横四海》浏览器版，升级为**服务器权威的多人在线文字网游**，并参考《大航海时代》系列，扩展为「文字版大航海时代」级玩法。

**技术栈**：Node.js（单进程，HTTP + WebSocket）+ SQLite（WAL）+ 内存状态 registry + 本地大模型（ollama qwen）驱动的 AI 系统。零第三方 npm 依赖（纯 Node 内置模块 + 本地 SQLite）。

## 核心特性

### 世界与叙事
- **12 大世界区域**：地中海 / 北海 / 西非 / 东非红海 / 印度洋 / 东南亚 / 东亚·中国 / 东亚·日本 / 新大陆·玛雅 / 加勒比 / 南美 / 极地，各配文化主题 / 发现物 / 主线章节 / 势力 / 关键 NPC。
- **12 章史诗主线**（集齐龙珠→四海之王）、80+ 关键 NPC、47 条支线、44 个发现物、30 个本土船员、21 项职业技能。

### 服务器权威多人在线
- 玩家账号（JWT + scrypt），状态全部服务器落盘（SQLite WAL）。
- WebSocket 实时世界广播；同城玩家可见；AI 玩家与世界共存。

### 动态世界经济
- 商品价格**动态变化**：区域基准（产区 0.75 / 异区 1.25）× 区域供需周期 × 天气影响 × 随机波动。
- **随机世界事件**（海盗 / 丰收 / 旱灾 / 风暴 / 瘟疫 / 商集 / 珍稀发现…）作用于价格与天气，并产生新遭遇。
- 玩家通过「天下页」情报（天气 / 供需 / 事件 + 套利提示）**主动收集信息**判断买卖时机，体现信息不对称的经济决策深度。

### 大航海玩法（7 批）
- **市场套利** / **装备强化**（15 级、失败不降）/ **宠物**（30 只、上限 3、出战伤害）
- **探索发现 + 声望爵位**（水手→船长→提督→总督→公爵）
- **船员随从**（招募上限 5，属性加成）+ **技能职业**（技能树）
- **商会 + 城市占领 / 税收**（影响力投资、占领区免税+日税）
- 战斗 / 航海 / 钓鱼 / 潜水 / 地牢 / 掉落等完整玩法

### AI 驱动系统（本地大模型，无需联网）
- **分层模型**：内容生成用 qwen3.8-4b-distill，极高频超短任务用 2b，9b 备用；`keep_alive=-1` 常驻 + 顶层 `think:false`，常驻后 <1s 实时响应。
- **9 个 AI 场景**：NPC 情境台词 / 世界事件播报 / 市场情报综述 / 经济事件生成 / 战斗叙述 / AI 玩家决策 / 市场顾问 / 发现物探索叙事 / 任务情境叙述。
- **AI 玩家**：3 名 AI 船员（ollama 决策 + 规则执行层）与世界共存。

## 快速开始

### 可玩版（下载 ZIP）
[下载可玩版 `zhsh-remake.zip`](downloads/zhsh-remake.zip?raw=1)

1. 完整解压 ZIP，不要在压缩软件里直接运行。
2. Windows 已安装 Node.js 22 或更高版本。
3. 双击 `启动游戏.cmd`，游戏服务以**系统托盘**方式常驻后台，浏览器自动打开游戏页面；不再保留命令行窗口。
4. 停止服务：右键托盘图标选择「停止服务器」或「退出」。

> 可玩版无需安装 npm 依赖。**注意**：可玩版为单人浏览器版；本仓库的**服务器权威版**请见下方「从源码运行」。

### 服务器权威版（从源码运行）

```powershell
cd <仓库根目录>
node server/server.js
```

服务器监听 `http://0.0.0.0:4173`（可用 `PORT` 环境变量调整）。浏览器打开 `http://127.0.0.1:4173/`，注册账号即可进入。

- 局域网其他设备：`http://<本机局域网IP>:4173/`。
- 存档位于 `server/data/`（账号库 accounts.db / 玩家库 players.sqlite / 运行时库 runtime.sqlite / 经济状态 economy.json），服务器落盘。
- 经济 tick / AI tick 间隔可用 `ZHSH_ECO_TICK_MS` / `ZHSH_AI_TICK_MS` 调整。

### AI 模型（可选，增强体验）
AI 系统依赖本地 ollama（默认 `http://127.0.0.1:11434`，`qwen3.8-2b/4b-distill`、`qwen3.5:9b`）。未部署时 AI 场景走规则保底（游戏核心玩法不受影响）。模型可用 `ZHSH_AI_MODEL` / `ZHSH_AI_MODEL_LIGHT` / `ZHSH_AI_MODEL_FAST` 切换。

### 单人浏览器版（保留）
双击 `启动游戏.vbs`（无控制台）或 `node scripts/dev-server.js`，打开终端显示的本地地址。单人版存档在本机 `web/.zhsh-player-saves.sqlite`（不上传外部）。

## 构建与数据

```powershell
# 重新生成数据库与浏览器内容
node scripts/import-content.js
node scripts/build-browser.js
```

重新生成内容后，服务器权威版的 `server/data/runtime.sqlite` 会基于内容库重建。

## 项目结构

```
server/           # 权威服务器：HTTP/WS 端点、认证、经济引擎、AI 系统
server/content/   # 12区世界/商品/发现物/宠物/主线/角色/支线/船员/技能/城市 等数据
server/ai/        # AI 决策服务、NPC台词、播报、战斗/发现物/任务叙述
server/eco/       # 世界经济引擎（动态价格/天气/事件）+ AI 情报/顾问
src/task-runtime/ # 游戏引擎（任务/战斗/经济/装备/宠物/船员/商会等 Runtime）
web/              # 前端（服务器权威版 app.js + game-api.js）
tests/            # 集成测试与基准
docs/             # 复原资料、任务索引、冲突记录、设计决策
data/             # 内容库
scripts/          # 构建/导出/校验脚本
```

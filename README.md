# 《纵横四海》高保真复原

这是一个面向 QQ 家园《纵横四海》怀旧玩家的非官方复原项目。仓库保存可玩版本、完整源码、任务与世界数据，以及多源资料整理结果，方便后续查阅、研究和体验。

## 下载与试玩

[下载可玩版 `zhsh-remake.zip`](downloads/zhsh-remake.zip?raw=1)

使用方法：

1. 完整解压 ZIP，不要在压缩软件里直接运行。
2. Windows 已安装 Node.js 22 或更高版本。
3. 双击 `启动游戏.cmd`，游戏服务将以**系统托盘**方式常驻后台（右下方通知区域图标“纵横四海服务器”），浏览器自动打开游戏页面；不再保留命令行窗口。
4. 需要停止服务时，右键托盘图标选择「停止服务器」或「退出」。

 可玩版无需安装 npm 依赖。角色存档保存在你本机的游戏服务器（`web/.zhsh-player-saves.sqlite`）中，不会上传到任何外部服务器；同一局域网内访问同一服务器的设备共用角色存档，默认进入最近使用的角色，可在「设置 → 角色管理」中切换或新建角色。

## 项目内容

- 651 条任务已整理进入浏览器内容。
- 229 张像素美术资产已完成实体、名称族、界面槽位或任务引用映射。
- 支持创建角色、任务接取与提交、战斗、装备、购买、航海、钓鱼及存档导入导出等流程。
- 保留多源复原资料、任务索引、冲突记录和设计决策，便于核查来源。

当前仍保留 3 条已知数据状态：`15.706` 为待验证项，`15.269` 与 `15.601` 为来源冲突项。这些内容没有被静默改写。

源码仓库已包含运行所需的本地 SQLite 数据库。安装 Node.js 22 或更高版本后：

- 双击仓库根目录的 `启动游戏.vbs`（无控制台窗口）即启动游戏服务并常驻系统托盘：右键托盘图标可「打开游戏 / 启动服务器 / 停止服务器 / 退出」。`启动游戏.cmd` 与 `启动游戏.vbs` 效果相同（前者会有一次极短暂的命令行窗口闪现）。游戏默认绑定 `0.0.0.0` 的 `20109` 端口，局域网内其他设备可用 `http://<本机局域网IP>:20109/` 访问；首次启动会自动检测并放行防火墙端口（权限不足时会提示一次管理员授权）。
- 或者手动执行 `node scripts/dev-server.js`，然后打开终端显示的本地地址。项目不依赖第三方 npm 包。

重新生成数据库与浏览器内容时，可执行：

```powershell
node scripts/import-content.js
node scripts/build-browser.js
```

完整测试：

```powershell
npm test
```

## 目录

- [`downloads/`](downloads/)：可直接解压运行的版本。
- [`web/`](web/)：浏览器界面与启动器。
- [`src/`](src/)：任务、数据和玩法运行层。
- [`data/`](data/)：运行数据、任务目录与规则数据。
- [`docs/research/`](docs/research/)：来源审计、任务索引和资料清单。
- [`docs/design/`](docs/design/)：复原目标、内容策略与叙事结构。
- [`docs/decisions/`](docs/decisions/)：已确认的项目决策。
- [`docs/reconstruction-baseline/`](docs/reconstruction-baseline/)：多源复原基线与冲突处理结果。
- [`tests/`](tests/) 与 [`browser-tests/`](browser-tests/)：自动化验证。

## 复原原则

项目优先保存原作已有的任务、名称、流程与系统行为。多源一致内容作为当前基线；单一来源且没有反证的内容暂时保留；来源冲突则明确记录，不把推测写成原版事实。

本项目为非官方、非商业的爱好者复原与资料保存项目，与原游戏运营方及相关权利人无关。仓库未附加开源许可证，不代表授予商业使用、重新发行或资产再利用权限；原作相关名称、设定及其他权利归相应权利人所有。

# 复原与后续优化政策

版本：0.2

状态：已确认

## 1. 目的与阶段边界

本政策用于建立面向怀旧玩家的高保真复原基线。当前阶段不预先决定删除、重写、压缩或转移任何原任务；先依据多个参考仓库、任务数据和其他历史资料还原完整、可运行、可验证的版本。

研究证据见[剧情证据审计](../research/story-source-audit.md)与[任务索引](../research/quest-index.md)。来源尚未完全确认时应标记可信度，不得据此主动删除内容。

## 2. 当前阶段的处理顺序

### 2.1 原样保留

剧情、任务、对白、NPC、名称、道具、等级、系统行为和任务流程默认保持来源原貌。内容显得陈旧、重复、奇幻、恶搞或时代错位，不构成修改理由。

### 2.2 多源校对

对比全部参考仓库中的任务、剧情、对白、NPC、道具、等级和系统行为。多个来源基本一致时，采用一致版本作为当前复原基线，不要求用户重新编写已有内容。

### 2.3 单源暂定

某项内容只有一个来源、且没有其他证据反驳时，先纳入复原基线，同时记录来源和可信度，不擅自删除或重写。

### 2.4 冲突标记

多个来源明显冲突时记录各版本差异，根据完整度、代码可运行性、任务前后关系和其他资料形成暂定结论。无法判断时列为待核实，不把推测伪装成原版事实。

### 2.5 技术修复

允许直接修复任务无法接取或提交、前后置断裂、NPC 或地点字段明显错误、页面链接失效、配置格式或代码错误、安全漏洞、数据无法加载和跨设备显示问题。修复目标是恢复资料原本表达的内容与行为，不得夹带内容优化。

### 2.6 缺失内容待核实

资料没有给出、来源只留下断点或无法从冲突版本中判断的内容保持开放。不得自行补写前后因果、对白、人物关系、玩法规则或结局。

## 3. 当前默认保留的内容

现阶段原样保留三聚氰胺相关任务，警察、警察局、探长、卧底等称呼，毒枭、现代犯罪和社会热点内容，以及龙珠、圣火令、玄铁重剑、聚宝盆、妖气长安、八仙、蓬莱和妖魔等题材。

模板化连续打怪、重复跑图、送信、送物、食材收集、任务堆叠和带有恶搞性质的任务也纳入复原基线。证据等级与原版归属可以继续标注，但不改变当前保留原则。

## 4. 复原记录最低要求

每项校对或修复至少记录：

1. 内容或系统名称。
2. 已检查的来源和对应位置。
3. 多源一致、单源暂定、冲突或缺失状态。
4. 当前采用版本及依据。
5. 若为技术修复，记录错误表现、预期源码行为和验证结果。

## 5. 完整可玩版本后的优化

只有完整可玩、可验证的复原版本建立后，才能由单独任务评估：

- 可选的任务压缩模式。
- 更便捷的跑图方式。
- 自动战斗或加速选项。
- 重复任务体验优化。
- 新旧内容切换。
- 怀旧模式与优化模式。

后续优化不得破坏玩家体验原始任务、对白、流程和系统行为的能力，也不得反向覆盖复原基线。

# ADR-0001：项目方向

- 状态：已接受，内容策略已修订
- 日期：2026-07-17
- 决策范围：复原基线建立前的顶层产品与内容方向

## 背景

项目主要服务对《纵横四海》有怀旧需求的玩家。现有资料来自多个复刻仓库，完整度、原版归属、可运行性和实现质量不一致；此前“主动现代化改编”的策略可能使旧任务、对白、名称和流程在完整复原前被提前改变，无法满足怀旧玩家核对与体验原有内容的需要。

## 决策

1. 项目仍使用现代技术重新实现，安全性、可维护性、响应式界面和移动端体验可以现代化。
2. 内容策略由“主动现代化改编”修正为“高保真复原优先”。
3. 剧情、任务、对白、人物、道具、名称、系统行为和玩法顺序默认按现有资料复原。
4. 多仓库比对是任务、剧情和系统定稿的主要方法；多源一致内容默认采用，单源无反证内容先保留。
5. 多源冲突应记录差异并形成有依据的暂定版本；无法判断时列为待核实。
6. 当前只直接处理明确技术错误，不把技术修复与内容优化混为一谈。
7. 任务流程和重复体验优化推迟到完整可玩版本完成以后，并由单独任务评估。
8. 不删除已经确认的重要主线和旧任务内容，包括现实题材、时代错位内容、跨作品元素、龙珠及东方神话长线。

## 撤回的旧原则

- 撤回当前阶段主动现代化重写旧对白、称呼和时代包装的原则。
- 撤回当前阶段预先合并压缩、转为可选或删除重复任务的原则。
- 撤回仅凭“不合理、陈旧、重复、恶搞或原版归属未完全确认”改变内容的原则。
- 撤回脱离源码另行规定系统开放顺序的原则；能由源码确定的行为和顺序直接进入复原基线。

## 影响

- 首要里程碑改为完整、可运行、可验证的复原版本。
- 参考源码不直接复制，但其任务数据、系统行为和内容顺序是重新实现的重要依据。
- 技术现代化不得改变内容基线。
- 后续优化必须保留怀旧模式、原始内容入口或其他等价的原貌体验能力。
- 尚无证据支持的连接和结局继续保持待核实，不自行补写。

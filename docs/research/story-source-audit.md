## 1. 执行摘要

1. 【A/D】仓库有一份完整的七段式开场文案：海边酒馆听冒险故事、乘帆船离乡、遭海盗登船；但没有路由通向 `intro.ejs`。实际新用户登录后直接进 `/main`，默认位置为威尼斯酒馆。因此只能确认“开场文案存在”和“代码实际起点在威尼斯酒馆”，不能确认玩家正常流程一定看得到海盗开场。证据：`views/pages/intro.ejs:23-69`；`index.js:111-178`；`src/city.js:12-26`。
2. 【A】最明确的新手链是 `task1.json` index -1–11：酒馆老板→福利官→卡萨诺→里皮→小皮特→里皮→雅典凯瑟琳→威尼斯因扎，教授找 NPC、走地图、打怪、购物，最后隐式要求跨城。证据：`config/task/task1.json`；前置实现见 `src/task.js:590-648`。
3. 【A/B】仓库没有一个从新手起点一直强制延伸到最终任务的单一主线。代码把 15 个任务文件当作 15 个独立系列，每个文件首项都可在等级满足时独立开始。证据：`src/task.js:215-262, 590-648`；各文件首项。
4. 【A/C/D】前期最像整体故事的线索链是 `task5/32–38`：神秘铁箱→神秘图纸→潜水器材料→海皇宝箱→箱中物→神秘徽章→伦敦詹姆斯。该链连续且 38 明写“关键任务”，但“箱中物是否就是徽章”只可推断；詹姆斯没有解释真相，39 立即回到送好酒，线索断裂。证据：`config/task/task5.json` index 32–39。
5. 【A/E】中后期存在一条仓库作者明确当作主线主体的长链：`task15` 的“寻裔之路”（180–210）→“聚宝盆”（211–312）→“妖气长安”（400–738，对应标题编号 1–350）。它在代码上连续，帮助页也称主线内置到“妖气长安350”；但大量龙珠、武侠、八仙、现代警匪、网络口语和跨作品人物使其原版归属高度可疑。证据：`views/pages/help.ejs:14,22-23`；`config/task/task15.json`。
6. 【A】城市没有任务解锁机制。导航页可切换地中海、北海、非洲、东亚、印度洋、新大陆并直接列出所有城市；任务只是叙事上依次要求前往雅典、伊斯坦堡、伦敦、泉州、杭州、京都等。证据：`views/pages/navigation.ejs:6-37`；`config/worldMap.json`；`src/sailing.js:58-85`。
7. 【A/B】航行的唯一硬条件是背包有 type=12 船只；船老板从一开始就在威尼斯码头，最低价船 1000 铜贝。若不消费，新手链完成 index 4 后累计任务铜贝为 1200，经济上首次足以买船，但没有任务明确送船或宣布解锁。证据：`src/sailing.js:23-34,58-85`；`config/ship.json`；`config/task/task1.json`。
8. 【A】“船队”不是独立编队系统，而是角色状态页链接到背包船只清单；持船上限按等级为 `min(6, floor(level/10)+1)`。1级最多1艘，10级起2艘，最多6艘。证据：`views/pages/role-status.ejs:203-207`；`views/pages/ships.ejs`；`src/npc.js:212-238`。
9. 【A】市场/贸易从系统层面一开始就存在，没有正式解锁任务；买市场商品受资金和船只总载重限制。连续“运货/通商”任务到 `task13/101`（36级）才出现，所以“早期可用、中期任务化并产生明确叙事价值”是最准确描述。证据：`src/npc.js:156-238,315-444,648-657`；`config/task/task13.json` index 101–108 等。

## 2. 证据等级与用语

- A：源码或配置明确写出。
- B：多条连续任务、对白或解锁关系可以较强推断。
- C：只有零散线索，无法确认。
- D：不同文件、字段或界面与实现之间存在矛盾。
- E：明显带有作者补写、恶搞、现代梗、跨作品拼接或非原版嫌疑。

本报告用“仓库主线”“复刻项目主线”称呼 `task15`，不用“官方原版主线”。“疑似主线”表示叙事连续或有“关键任务”文字，但没有完整、可靠的全局链路。

## 3. 源码能够证明的游戏开场

### 3.1 存在的开场文案

`views/pages/intro.ejs` 明确写出以下顺序：【A】

1. 金色沙滩、蔚蓝海洋和海边小镇酒吧；世界各地的水手、冒险者在酒吧饮酒谈经历（23–27）。
2. 话题包含地中海希腊神话、北海女巫、非洲大陆、古代中国（30–35）。
3. 危险包含海妖、巨兽、吸血鬼、木乃伊（37–41）。
4. 第一人称玩家听得入迷，背上行囊、登上远航帆船（44–48）。
5. 玩家告别熟悉小镇、驶向未知（51–55）。
6. 航行中被大船撞击，海盗登船包围玩家（58–62）。
7. 海盗船长宣称玩家的航海梦想结束，链接随后指向 `main`（65–69）。

这份文案能证明复刻仓库设计过“出海即遭海盗”的开场，不能证明该开场来自官方原版。【A/C】

### 3.2 实际代码可达起点

- 登录成功直接 `res.redirect('/main')`，注册成功先回登录页；全仓没有发现 `/intro` 路由或渲染调用。【A】证据：`index.js:111-178`；全仓 `rg intro` 只命中模板本身。
- 新建 `User` 会新建 `City`；`City` 构造器默认 `city="威尼斯"`、`position="酒馆"`。【A】证据：`src/user.js:20-32`；`src/city.js:12-21`。
- 战败重置位置却是威尼斯福利院，不是酒馆。【A】证据：`src/city.js:23-27`；`src/monster.js:281-305`。

结论：玩家“数据起点”可确定为威尼斯酒馆；“正常界面流程是否先播放海盗开场”不能确定，现有路由反而显示不会播放。【D】

### 3.3 最早可见和最早任务 NPC

- 威尼斯酒馆配置同时有怪博士、老板（新手指引）、罗西、安德鲁、露丝，以及后期 NPC。【A】证据：`config/npcs.json` 的威尼斯/酒馆。
- 任务系统会把当前等级满足、前置满足的接取 NPC 动态放到当前位置。1级时最明确可接首项是老板（新手指引）的 index -1；其他文件首项多有 2、5、6、8、9、10 等等级要求。【A】证据：`src/npc.js:705-749`；各 `taskN.json` 首项。
- index -1 的对白以“这都已经不重要了”开头，并说玩家是从“奇怪世界”来的、一丝不挂，说明此前可能缺了一段承接海盗事故或异世界到达的对话。【C/D/E】证据：`config/task/task1.json` index -1。

## 5. 疑似主线完整时间线

### 5.1 前期“铁箱—徽章”候选主线

1. `task5/21–23`：罗西想要好酒→酒馆老板→威尼斯公主→去伊斯坦堡买狮子奶。【A】
2. `24–26`：公主转介治安官多纳多，清剿威尼斯海贼与头目。【A】
3. `27–31`：多纳多转介安德鲁；玩家打灰熊、棕熊、猛虎、猴子，文案称学习攻击、防御、敏捷。【A】但奖励只有经验/声望/铜贝，没有技能或属性解锁。【D】
4. `32`：安德鲁让玩家在拉古扎—雅典航线钓神秘铁箱。【A】
5. `33–34`：铁箱送卡萨诺，再转小卡萨诺；34 标题/目标写“神秘图纸”，对白仍说“这个神秘铁箱”。【A/D】
6. `35–36`：收集鲨鱼皮制作特殊工具/潜水器；在伊斯坦堡—雅典航线潜水进海皇宫殿，取海皇宝箱中的魔法水晶。【A/E】
7. `37`：小卡萨诺开箱，让玩家把“里面的东西”交公主；物品没有名称。【A/C】
8. `38`：公主给“神秘徽章”，让玩家去北海伦敦酒馆找詹姆斯，内容明写“关键任务”。【A】“箱中物=徽章”是合理但未明写的 B 级推断。
9. `39`：詹姆斯没有解释徽章，只给好酒让玩家带回威尼斯给罗西；且接取地点错误写成威尼斯王宫。【D】

结论：这条链最适合作为前期现代重制的“候选悬疑骨架”，但现有源码没有给出谜底，不能声称神秘铁箱、图纸、宝箱、徽章和詹姆斯已经构成完整故事。【B/C/D】

### 5.4 是否存在清晰、连续的主线

- 仓库内部：有，`task15` 是清晰的代码连续长链，且作者帮助页把它称为主线的一部分。【A】

## 10. 战斗、航行、船只、船队和贸易开放顺序

### 10.1 战斗

- 初始即可使用；`task1/1` 是第一项明确战斗教学。【A】
- 形式是玩家与人物/怪物轮流数值对抗。每次点击“攻击”执行玩家攻击、宠物攻击（若有）、怪物反击；可攻击、自动攻击、用药、查看、撤退。【A】证据：`views/pages/attack.ejs`；`src/monster.js:159-355`。
- 核心属性包括生命、攻击上下限、防御、敏捷、士气，另有暴击、异常状态、装备、套装、宠物。【A】证据：`src/play.js:17-54,65-195`；`src/monster.js:18-50`。
- 防御通过 `defense/(defense+300)` 形成减伤，敏捷差影响伤害和暴击；最小伤害1。【A】证据：`src/monster.js:24-49`。
- 失败会回威尼斯福利院、生命置1，并丢失全部市场商品；页面还显示损失500铜和士气7，但相应扣减不完全在此返回逻辑中体现，存在实现疑点。【A/D】

### 10.2 船只与航行

1. 船老板从开局存在；买船只受货币和持船上限限制。【A】
2. 只要背包有船即可在导航页选目的城市并航行，无任务门槛。【A】
3. 新手链在 index10 首次要求去雅典，因此玩家最迟此时必须解决船只问题；若不消费，完成 index4 后已有足够铜贝买最低价船，这是资金推断，不是任务解锁。【B】
4. 航行中可继续航行、自动航行、返航、钓鱼、潜水，并随机遇到事件/副本。【A】
5. `task5/32` 才首次把航线钓鱼写入疑似主线；`task5/36` 首次把航线潜水写入疑似主线。【A】

### 10.3 船队

- 没有发现独立的船队编成、旗舰、船员或队形状态。页面只是罗列背包所有船只。【A】
- 代码允许多船并把所有船的载重相加；等级决定最多船数。【A】
- 因此“船队在什么阶段出现”的准确答案是：界面入口从开始存在；1级只有1艘上限，10级起技术上形成多船集合；没有任务正式开放。【A】

### 10.4 贸易/跑商

- 市场买卖页面和各城市商品/售价配置从开始存在。【A】
- 市场商品购买需要船只总载重，否则失败；新角色初始铜贝为0，所以实际先要完成任务或战斗获得本金并买船。【A】
- 异地卖价来自 `scp.json`；同城大量卖出会触发每100件一次、最多5次的临时降价。【A】证据：`src/npc.js:340-443`。
- 航行事件会损失市场货物、触发海盗或在携带100件以上市场商品时有机会给套装装备。【A】证据：`src/sailing.js:198-527`；`views/pages/help.ejs:6`。
- 第一组正式运货叙事是 `task13/101`，等级36，但它没有设置任何贸易 unlock。【A】

结论：跑商不是由某项任务正式解锁；它是开局系统能力，受船、载重、本金制约，中期由通商任务赋予明确目标和实际价值。【A/B】

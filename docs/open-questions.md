# 待解决问题

本文件只记录多源冲突、资料缺失和现有源码无法回答的问题。源码已经明确的系统不要求用户重新设计；来源未确认的内容继续保留并标记，不因此删除或改写。

## 多源校对

- 各参考仓库之间有哪些任务、对白、NPC、道具、等级和系统行为基本一致？
- 各仓库之间的明显冲突有哪些，哪一版本在完整度、可运行性和任务前后关系上更适合作为暂定基线？
- 哪些内容目前只有单一来源，后续能否由旧资料或玩家口述交叉验证？

## 叙事缺失

- 各独立任务文件在原游戏中是否存在统一的主线顺序？
- 海盗开场与威尼斯酒馆起点之间是否存在缺失内容？
- 詹姆斯、徽章、铁箱、图纸和箱中物的真实后续是什么？
- 龙珠、寻裔之路、聚宝盆与妖气长安之间是否存在缺失的跨系列连接？
- 当前地魔任务之后是否还有最终敌人、正式结局或后续章节？

## 系统冲突与缺失

- 不同参考仓库中的战斗、自动攻击、药品、宠物、装备和打造行为有哪些实质差异？
- 不同参考仓库中的船只、船队、市场、航行、钓鱼和潜水规则有哪些实质差异？
- 现有实现中的任务断裂、地点错误、费用方向错误和配置字段错位，哪些能确定为技术错误，哪些可能反映不同版本？

## 发布前核验

- 现有名称和跨作品元素在公开发布时涉及哪些授权或合规限制？该核验不得反向改写内部复原基线。
- 后续是否能找到更多旧资料、截图、录屏或玩家口述，并建立可追溯的证据等级？

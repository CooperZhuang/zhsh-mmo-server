# 项目文档

本目录保存《纵横四海》复原过程中形成的资料与决策记录。

- [`research/`](research/)：来源清单、剧情审计和任务索引。
- [`design/`](design/)：项目方向、内容策略、叙事结构和美术映射。
- [`decisions/`](decisions/)：已经确认的关键决策。
- [`reconstruction-baseline/`](reconstruction-baseline/)：多源复原基线、冲突覆盖层和验证摘要。
- [`open-questions.md`](open-questions.md)：仍待核实的问题。

这些材料用于说明当前复原依据，不等同于官方资料。多源一致、单源暂定、用户确认、源码推断和来源冲突在文档中分别记录。
